# Generated LaTeX

`resume render` writes `resume.tex` here. The canonical parameterized template is
packaged at `pkg/resume/latex/resources/resume.tex.j2`, so installed wheels work outside
the source checkout. Set `template` in `resume.reference.yaml` to override it.

Generated LaTeX is ignored; CI uploads it with the PDF for inspection. Edit the
template or input snapshot, then regenerate. Do not edit the generated file.
